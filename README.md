# Démo · Dépôt de capital (Nova Pro)

Maquette de l'espace dépôt de capital : vue fondateur, console interne, conversations partenaire, tableau de bord.
Tourne en mode simulé (aucun compte Swan ni Gmail requis).

```bash
npm install
npm start            # http://localhost:3100
npm run demo         # dans un 2e terminal : crée 3 dossiers de démo
```

Node ≥ 22.5 (base SQLite intégrée `node:sqlite`). Variables facultatives : voir `.env.example`.
